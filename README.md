# Module 3 Dashboard

A small Vite + vanilla JavaScript dashboard that pulls a list of users from a public API and shows a quick summary plus a card for each person.

It’s mainly practice for:
- async/await + `fetch`
- try/catch error handling
- ES modules
- array methods (`map`, `filter`, `reduce`)
- the spread operator
- destructuring
- template literals
